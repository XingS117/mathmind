# 三角形全等与中位线定理综合证明

### 1. 原题重现
**题目**：如图，在 $\triangle ABC$ 中，$AB = AC$，延长 $AB$ 到点 $D$，使 $BD = AB$，点 $E$ 是 $AB$ 的中点，连接 $CD, CE$。求证：$CD = 2CE$。

### 2. 核心考点

- 等腰三角形的性质
- 全等三角形的判定（SAS）与性质
- 三角形中位线定理

### 3. 破局关键
**构造三角形中位线**是本题的“题眼”。通过取 $AC$ 中点 $F$ 并连接 $BF$，将证明 $CD=2CE$ 巧妙转化为证明 $CD=2BF$（中位线性质）与 $BF=CE$（全等三角形性质）。

### 4. 答案解析
**证明**：如图，取 $AC$ 的中点 $F$，连接 $BF$。
$\because AB=AC$，点 $E, F$ 分别是 $AB, AC$ 的中点，
$\therefore AE=AF$。
在 $\triangle ABF$ 和 $\triangle ACE$ 中，
$\because \begin{cases} AB=AC, \\ \angle BAF=\angle CAE, \\ AF=AE, \end{cases}$$\therefore \triangle ABF \cong \triangle ACE(SAS)$，
$\therefore BF=CE$。
$\because BD=AB$，$AF=CF$，
$\therefore BF$ 是 $\triangle ACD$ 的中位线，
$\therefore CD=2BF$，
$\therefore CD=2CE$。
