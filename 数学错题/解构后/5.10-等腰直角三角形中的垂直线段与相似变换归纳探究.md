### 4. 答案解析
**(1)证明：** 当 $n=1$ 时，$\frac{BD}{CD} = \frac{1}{n} = 1$，$\therefore BD = CD$。
如图1，在 $\text{Rt}\triangle ABC$ 中，$\angle A = 90^\circ$，$AB = AC$，连接 $AD$。
$\therefore AD = \frac{1}{2}BC = BD$，$\angle DAF = \frac{1}{2}\angle BAC = 45^\circ$，$AD \perp BC$，$\angle B = \angle C = 45^\circ$。
由勾股定理得：$BC = \sqrt{AB^2 + AC^2} = \sqrt{2}AC$。
$\therefore \angle B = \angle DAF$。
$\because DE \perp DF$，
$\therefore \angle EDF = \angle ADB = 90^\circ$，
$\therefore \angle BDE = \angle ADF = 90^\circ - \angle ADE$。
在 $\triangle BDE$ 和 $\triangle ADF$ 中，
$\begin{cases} \angle BDE = \angle ADF \\ BD = AD \\ \angle B = \angle DAF \end{cases}$$\therefore \triangle BDE \cong \triangle ADF (\text{ASA})$。
$\therefore BE = AF$。
$\therefore BE + CF = AF + CF = AC$。
又 $\because BC = \sqrt{2}AC$，
$\therefore BE + CF = \frac{\sqrt{2}}{2}BC$。
**(2)解：**$BE + \frac{1}{2}CF = \frac{\sqrt{2}}{3}BC$；理由如下：

$\therefore BH = GH$，$\angle BHG = 90^\circ$（注：原图标答图片误写为$\angle BHC=90^\circ$，应为笔误），即 $\triangle BHG$ 为等腰直角三角形。
由(1)可得 $BE + MG = \frac{\sqrt{2}}{2}BG$。
$\because MG \parallel CF$，
$\therefore \triangle DGM \sim \triangle DCF$，
$\therefore \frac{MG}{FC} = \frac{DG}{DC} = \frac{1}{2}$，
$\therefore MG = \frac{1}{2}CF$。
又 $\because BG = \frac{2}{3}BC$，$BE + MG = \frac{\sqrt{2}}{2}BG$，
$\therefore BE + \frac{1}{2}CF = \frac{\sqrt{2}}{3}BC$。
故答案为：$BE + \frac{1}{2}CF = \frac{\sqrt{2}}{3}BC$。

$\therefore BE + \frac{1}{3}CF = \frac{\sqrt{2}}{4}BC$。

### 5. 影子练习 (变式训练)
**变式题一（同源模型巩固）**
在 $\text{Rt}\triangle ABC$ 中，$\angle A = 90^\circ$，$AB = AC$，$D$ 是 $BC$ 的中点。一个直角 $\angle EDF = 90^\circ$ 绕着点 $D$ 旋转，其两边分别与 $AB$ 边和 $AC$ 边交于点 $E, F$。
(1) 求证：$DE = DF$；
(2) 探究线段 $BE, CF, EF$ 之间的数量关系，并证明。
**(1) 证明：**
连接 $AD$。
$\because \angle A = 90^\circ$，$AB = AC$，$D$ 是 $BC$ 中点，
$\therefore AD \perp BC$，$AD$ 平分 $\angle BAC$。
$\therefore AD = BD = CD$，$\angle B = \angle DAF = 45^\circ$。
$\because DE \perp DF$，$\therefore \angle EDF = 90^\circ$。
又 $\because AD \perp BC$，$\therefore \angle ADB = 90^\circ$。
$\therefore \angle BDE + \angle ADE = \angle ADE + \angle ADF = 90^\circ$，
$\therefore \angle BDE = \angle ADF$。
在 $\triangle BDE$ 和 $\triangle ADF$ 中，
$\begin{cases} \angle BDE = \angle ADF \\ BD = AD \\ \angle B = \angle DAF \end{cases}$$\therefore \triangle BDE \cong \triangle ADF (\text{ASA})$。
$\therefore DE = DF$。
**(2) 解：数量关系为 BE2+CF2=EF2。**
证明：由 (1) 中 $\triangle BDE \cong \triangle ADF$ 可知 $BE = AF$。
在 $\text{Rt}\triangle ABC$ 中，点 $E$ 在 $AB$ 上，点 $F$ 在 $AC$ 上，
$\because \angle A = 90^\circ$，
在 $\text{Rt}\triangle AEF$ 中，根据勾股定理有：$AE^2 + AF^2 = EF^2$。
$\because AB = AC$，
$\therefore AE = AB - BE = AC - AF = CF$（或直接利用 $AE=AC-CF, BE=AF$，则 $BE^2+CF^2 = AF^2+AE^2$）。
$\therefore BE^2 + CF^2 = EF^2$。
**变式题二（一线三等角拓展延伸）**
等边 $\triangle ABC$ 的边长为 $a$，点 $D$ 在边 $BC$ 上，且 $BD = \frac{1}{3}BC$。过点 $D$ 作 $\angle EDF = 60^\circ$，其两边分别交射线 $AB$ 于点 $E$，交射线 $AC$ 于点 $F$。
(1) 证明：$\triangle BDE \sim \triangle CFD$；
(2) 若 $BE = x$，请用含 $a$ 和 $x$ 的代数式表示 $CF$ 的长度。
**(1) 证明：**$\because \triangle ABC$ 是等边三角形，
$\therefore \angle B = \angle C = 60^\circ$。
$\therefore \angle BDE + \angle BED = 180^\circ - \angle B = 120^\circ$。
又 $\because \angle EDF = 60^\circ$，点 $D$ 在直线 $BC$ 上，
$\therefore \angle BDE + \angle CDF = 180^\circ - \angle EDF = 120^\circ$。
$\therefore \angle BED = \angle CDF$。
在 $\triangle BDE$ 和 $\triangle CFD$ 中，
$\begin{cases} \angle B = \angle C = 60^\circ \\ \angle BED = \angle CDF \end{cases}$$\therefore \triangle BDE \sim \triangle CFD$。
**(2) 解：**$\because \triangle ABC$ 的边长为 $a$ 且 $BD = \frac{1}{3}BC$，
$\therefore BC = a$，$BD = \frac{1}{3}a$，$CD = BC - BD = \frac{2}{3}a$。
由 (1) 知 $\triangle BDE \sim \triangle CFD$，
$\therefore \frac{BE}{CD} = \frac{BD}{CF}$。
将 $BE = x$，$BD = \frac{1}{3}a$，$CD = \frac{2}{3}a$ 代入比例式得：
$\frac{x}{\frac{2}{3}a} = \frac{\frac{1}{3}a}{CF}$，
解得：$CF = \frac{\frac{1}{3}a \cdot \frac{2}{3}a}{x} = \frac{2a^2}{9x}$。
