# 圆的切线判定与相似三角形综合探究

### 1. 原题重现
如图，四边形 $ABCD$ 内接于 $\odot O$，连接 $AC$、$BD$，过点 $B$ 向圆外方向作 $\angle CBE = \angle BDC$，点 $E$ 在 $AC$ 的延长线上。
(1) 求证：$EB^2 = EC \cdot EA$；
(2) 求证：$EB$ 为 $\odot O$ 的切线.

### 2. 核心考点

- **圆周角定理**：同弧或等弧所对的圆周角相等；半圆（或直径）所对的圆周角是直角。
- **相似三角形的判定与性质**：两角分别相等的两个三角形相似；相似三角形对应边成比例。
- **圆的切线判定定理**：经过半径的外端并且垂直于这条半径的直线是圆的切线。

### 3. 破局关键

- **第一问**：识别出“同弧所对圆周角相等”进行等量代换（$\angle BDC = \angle BAC$），将条件转化为 $\angle CBE = \angle BAC$，再结合公共角 $\angle E$ 构造 $\triangle BCE \sim \triangle ABE$。
- **第二问**：遇到切线判定，无切点连线时常采用“作垂直证半径”或“连半径证垂直”。本题通过构造直径辅助线，利用直径所对圆周角为 $90^\circ$，结合第一步的角度代换，通过角度和的拼凑得出 $\angle FBE = 90^\circ$ 从而破局。

### 4. 答案解析
**(1) 证明：**$\because \angle BAC = \angle BDC$, $\angle CBE = \angle BDC$,
$\therefore \angle BAC = \angle CBE$,
$\because \angle E = \angle E$,
$\therefore \triangle BCE \sim \triangle ABE$,
$\therefore \frac{EB}{EA} = \frac{EC}{EB}$,
$\therefore EB^2 = EC \cdot EA$;
**(2) 证明：**
连接 $OB$，延长 $BO$ 交 $\odot O$ 于点 $F$，连接 $CF$,
$\because \angle BDC$ 和 $\angle BFC$ 都是弧 $BC$ 所对的圆周角，
$\therefore \angle BDC = \angle BFC$,
又 $\because \angle CBE = \angle BDC$,
$\therefore \angle BFC = \angle CBE$,
$\because BF$ 是 $\odot O$ 的直径，
$\therefore \angle BCF = 90^\circ$,
$\therefore \angle CBF + \angle BFC = 90^\circ$,
$\therefore \angle CBF + \angle CBE = 90^\circ$，即 $\angle FBE = 90^\circ$,
$\therefore$ 直径 $BF \perp BE$,
$\therefore EB$ 为 $\odot O$ 的切线.

### 5. 影子练习 (变式训练)
**变式题一（同构反转变式）**
如图，$\triangle ABC$ 内接于 $\odot O$，点 $D$ 是 $\odot O$ 上一点，连接 $AD, BD$。过点 $A$ 作直线 $AE$ 交 $CB$ 的延长线于点 $E$，使得 $\angle EAB = \angle ADB$。
(1) 求证：$AE^2 = EB \cdot EC$；
(2) 求证：$AE$ 是 $\odot O$ 的切线。
**(1) 证明：**$\because \angle ACB$ 和 $\angle ADB$ 都是弧 $AB$ 所对的圆周角，
$\therefore \angle ACB = \angle ADB$。
$\because \angle EAB = \angle ADB$，
$\therefore \angle EAB = \angle ACB$ (即 $\angle ECA$)。
又 $\because \angle E = \angle E$，
$\therefore \triangle EAB \sim \triangle ECA$。
$\therefore \frac{EA}{EC} = \frac{EB}{EA}$，
$\therefore AE^2 = EB \cdot EC$。
**(2) 证明：**
连接 $AO$ 并延长交 $\odot O$ 于点 $F$，连接 $CF$。
$\because AF$ 是 $\odot O$ 的直径，
$\therefore \angle ACF = 90^\circ$。
$\therefore \angle AFC + \angle FAC = 90^\circ$。
$\because \angle AFC$ 和 $\angle ADB$ 都是弧 $AC$ 所对的圆周角 (或通过 $\angle AFC = \angle ABC$ 且 $\angle ADB = \angle ACB$ 推导，更直接的是 $\angle AFC = \angle ABC$)，
**注意更正证明路径**：利用同弧推导更简便。连接 $AO$ 延长交 $\odot O$ 于 $F$，连 $BF$。
$\because AF$ 是直径，$\therefore \angle ABF = 90^\circ$，即 $\angle AFB + \angle FAB = 90^\circ$。
$\because \angle AFB$ 与 $\angle ACB$ 对应同一段弧 $AB$，$\therefore \angle AFB = \angle ACB$。
由 (1) 知 $\angle EAB = \angle ACB$，
$\therefore \angle AFB = \angle EAB$。
$\therefore \angle EAB + \angle FAB = 90^\circ$，即 $\angle FAE = 90^\circ$。
$\because AF$ 为 $\odot O$ 的直径，
$\therefore AE \perp AF$，
$\therefore AE$ 是 $\odot O$ 的切线。
**变式题二（切线判定与相似计算综合进阶）**
如图，$AB$ 是 $\odot O$ 的直径，点 $C$ 是 $\odot O$ 上一点，连接 $AC$、$BC$，过点 $C$ 作直线 $CD$ 交 $AB$ 的延长线于点 $D$，使得 $\angle BCD = \angle A$。
(1) 求证：$CD$ 是 $\odot O$ 的切线；
(2) 若 $BD = 2$，$CD = 4$，求 $\odot O$ 的半径。
**(1) 证明：**
连接 $OC$。
$\because AB$ 是 $\odot O$ 的直径，
$\therefore \angle ACB = 90^\circ$，即 $\angle A + \angle CBA = 90^\circ$。
$\because OC = OB$ (都是 $\odot O$ 的半径)，
$\therefore \angle OCB = \angle CBA$。
$\because \angle BCD = \angle A$，
$\therefore \angle BCD + \angle OCB = \angle A + \angle CBA = 90^\circ$，即 $\angle OCD = 90^\circ$。
$\because OC$ 是 $\odot O$ 的半径，且 $CD \perp OC$，
$\therefore CD$ 是 $\odot O$ 的切线。
**(2) 解：**$\because \angle D = \angle D$，$\angle BCD = \angle A$，
$\therefore \triangle BCD \sim \triangle CAD$。
$\therefore \frac{CD}{AD} = \frac{BD}{CD}$，
$\therefore CD^2 = BD \cdot AD$。
$\because BD = 2$，$CD = 4$，设 $\odot O$ 的半径为 $r$，则 $AD = 2 + 2r$。
$\therefore 4^2 = 2 \times (2 + 2r)$，
解得：$16 = 4 + 4r \implies 4r = 12 \implies r = 3$。
$\therefore \odot O$ 的半径为 $3$。
