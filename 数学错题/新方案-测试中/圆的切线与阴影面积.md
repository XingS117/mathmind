### 2. 核心考点

- **切线的判定：** 证明直线与圆相切，核心使用“连半径，证垂直”（即证明 $\angle OCF = 90^\circ$）。
- **圆的基本性质定理：** 圆周角定理及其推论（直径所对的圆周角是直角）、等边对等角。
- **阴影面积计算：** 不规则图形面积的转化，通过割补法利用 $S_{\text{扇形}} - S_{\triangle}$ 来求解。

### 3. 破局关键

1. **切线证明的题眼：** 通过平行线 $CF \parallel AE$ 转移直角位置至 $\angle F$，并在 $\text{Rt}\triangle CFE$ 中通过角度代换，最终推导出 $\angle OCF = \angle OCE + \angle FCE = 90^\circ$ 即可破局。
2. **面积求解的题眼：** 判断出 $\triangle COE$ 是等腰直角三角形，进而将计算直接拆解为规范的“扇形面积减去直角三角形面积”。

### 4. 答案解析
**(1) 证明：**
连结 $OC$.
$\because AB$ 是 $\odot O$ 的直径，
$\therefore \angle AEB = 90^\circ$.
$\because CF \parallel AE$，
$\therefore \angle F = \angle AEB = 90^\circ$.
$\because OD \perp AB$，
$\therefore \angle BOD = 90^\circ$.
$\therefore \angle BED = \frac{1}{2} \angle BOD = 45^\circ$.
在 $\text{Rt}\triangle CFE$ 中，
$\angle FCE = 90^\circ - \angle BED = 45^\circ$.
$\because OC = OE$，
$\therefore \angle OCE = \angle OEC = \angle BED = 45^\circ$.
$\therefore \angle OCF = \angle OCE + \angle FCE = 45^\circ + 45^\circ = 90^\circ$.
$\therefore OC \perp CF$.
$\because OC$ 是 $\odot O$ 的半径，
$\therefore CF$ 为 $\odot O$ 的切线.
**(2) 解：**
由 (1) 得 $\angle OCE = \angle OEC = 45^\circ$，
$\therefore \angle COE = 180^\circ - 45^\circ - 45^\circ = 90^\circ$.
$\because AB = 4$，
$\therefore OC = OE = \frac{1}{2}AB = 2$.
$\therefore S_{\text{扇形}COE} = \frac{90\pi \times 2^2}{360} = \pi$.
$\because \triangle COE$ 为直角三角形，
$\therefore S_{\triangle COE} = \frac{1}{2} \times OC \times OE = \frac{1}{2} \times 2 \times 2 = 2$.
$\therefore S_{\text{阴影}} = S_{\text{扇形}COE} - S_{\triangle COE} = \pi - 2$.
答：阴影部分的面积为 $\pi - 2$.

**变式题 1**
如图，在 $\odot O$ 中，$AB$ 为直径，点 $C$ 在 $\odot O$ 上，$\angle BAC = 30^\circ$，$D$ 为 $\overset{\frown}{AC}$ 的中点，过点 $D$ 作 $DE \parallel AC$ 交 $BA$ 的延长线于点 $E$.
(1) 求证：$DE$ 是 $\odot O$ 的切线；
(2) 若 $AB = 4$，求阴影部分（由线段 $DE, AE$ 与 $\overset{\frown}{AD}$ 围成）的面积.
**(1) 证明：**
连接 $OD$.
$\because D$ 为 $\overset{\frown}{AC}$ 的中点，
$\therefore \overset{\frown}{AD} = \overset{\frown}{CD}$.
$\because OA = OC$，
$\therefore OD \perp AC$ （利用垂径定理的推论，或由于等腰 $\triangle OAC$ 中 $OD$ 平分顶角，故 $OD$ 垂直平分 $AC$）.
$\because DE \parallel AC$，
$\therefore OD \perp DE$.
$\because OD$ 是 $\odot O$ 的半径，且点 $D$ 在 $\odot O$ 上，
$\therefore DE$ 是 $\odot O$ 的切线.
**(2) 解：**$\because AB = 4$，$\therefore OD = OA = 2$.
$\because \angle BAC = 30^\circ$，$\therefore \angle BOC = 2\angle BAC = 60^\circ$.
$\therefore \angle AOC = 180^\circ - 60^\circ = 120^\circ$.
$\because \overset{\frown}{AD} = \overset{\frown}{CD}$，$\therefore \angle AOD = \frac{1}{2}\angle AOC = 60^\circ$.
在 $\text{Rt}\triangle ODE$ 中，$\angle ODE = 90^\circ$，$\angle DOE = 60^\circ$，$OD = 2$.
$\therefore DE = OD \cdot \tan 60^\circ = 2\sqrt{3}$.
$S_{\triangle ODE} = \frac{1}{2} \cdot OD \cdot DE = \frac{1}{2} \times 2 \times 2\sqrt{3} = 2\sqrt{3}$.
$S_{\text{扇形}OAD} = \frac{60 \cdot \pi \cdot 2^2}{360} = \frac{2\pi}{3}$.
$\therefore S_{\text{阴影}} = S_{\triangle ODE} - S_{\text{扇形}OAD} = 2\sqrt{3} - \frac{2\pi}{3}$.
答：阴影部分的面积为 $2\sqrt{3} - \frac{2\pi}{3}$.
**变式题 2**
如图，$\triangle ABC$ 内接于 $\odot O$，$AB$ 为直径，$\angle BAC$ 的平分线交 $\odot O$ 于点 $E$. 过点 $E$ 作 $\odot O$ 的切线交 $AB$ 的延长线于点 $F$.
(1) 求证：$EF \parallel BC$；
(2) 若 $AB = 4$，$\angle ABC = 45^\circ$，求阴影部分（由线段 $EF, BF$ 与 $\overset{\frown}{BE}$ 围成）的面积.
**(1) 证明：**
连接 $OE$.
$\because AE$ 平分 $\angle BAC$，
$\therefore \angle BAE = \angle CAE$.
$\therefore \overset{\frown}{BE} = \overset{\frown}{CE}$，即 $E$ 为 $\overset{\frown}{BC}$ 的中点.
$\because AB$ 为 $\odot O$ 的直径，
$\therefore \angle ACB = 90^\circ$，即 $AC \perp BC$.
$\because \overset{\frown}{BE} = \overset{\frown}{CE}$，$OE$ 为半径，
$\therefore OE \perp BC$.
$\because EF$ 是 $\odot O$ 的切线，点 $E$ 为切点，
$\therefore OE \perp EF$.
$\therefore EF \parallel BC$.
**(2) 解：**$\because \angle ACB = 90^\circ$，$\angle ABC = 45^\circ$，
$\therefore \angle BAC = 45^\circ$.
$\therefore \angle BOC = 2\angle BAC = 90^\circ$.
$\because E$ 为 $\overset{\frown}{BC}$ 的中点，
$\therefore \angle BOE = \frac{1}{2}\angle BOC = 45^\circ$.
在 $\text{Rt}\triangle OEF$ 中，$\angle OEF = 90^\circ$，$\angle EOF = 45^\circ$，$OE = \frac{1}{2}AB = 2$.
$\therefore \triangle OEF$ 为等腰直角三角形，$EF = OE = 2$.
$\therefore S_{\triangle OEF} = \frac{1}{2} \cdot OE \cdot EF = \frac{1}{2} \times 2 \times 2 = 2$.
$S_{\text{扇形}OBE} = \frac{45 \cdot \pi \cdot 2^2}{360} = \frac{\pi}{2}$.
$\therefore S_{\text{阴影}} = S_{\triangle OEF} - S_{\text{扇形}OBE} = 2 - \frac{\pi}{2}$.
答：阴影部分的面积为 $2 - \frac{\pi}{2}$.
